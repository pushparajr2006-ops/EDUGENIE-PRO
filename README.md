# EduGenie 🧠✨ — Gemini-Powered Learning Assistant

A lightweight AI tutor built with **FastAPI** + a simple **HTML/CSS/JS** frontend.

| Feature | Endpoint | AI engine |
|---|---|---|
| Ask a question | `GET /qa?question=...` | Google Gemini |
| Explain a concept | `POST /explain` | LaMini-Flan-T5-783M (local) → falls back to Gemini |
| Summarize text | `POST /summarize` | Google Gemini |
| Generate a 3-question quiz | `POST /quiz` | Google Gemini (JSON output) |
| Learning path | `GET /learn/recommendations?topic=...` | Google Gemini |

## 1. Prerequisites

* **Python 3.10 or newer** (check: `python --version`; on macOS/Linux maybe `python3 --version`)
* **VS Code** with the **Python** extension (VS Code will offer to install it)
* A free **Gemini API key** → https://aistudio.google.com/app/apikey
* Disk space/time for the local explanation model: ~3 GB download on first use  
  (optional — see "Skipping the local model" below)

## 2. Open the project in VS Code

1. Unzip `EduGenie.zip`.
2. VS Code → **File → Open Folder…** → choose the `EduGenie` folder.
3. Open a terminal: **Terminal → New Terminal**.

## 3. Create a virtual environment & install dependencies

**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements-dev.txt
```
> If activation is blocked: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, then retry.

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements-dev.txt
```

Then select the interpreter: press `Ctrl+Shift+P` (`Cmd+Shift+P` on Mac) → **Python: Select Interpreter** → choose the one inside `.venv`.

## 4. Add your API key

Copy `.env.example` to `.env` and put your key in it:

```bash
# Windows
copy .env.example .env
# macOS / Linux
cp .env.example .env
```
Edit `.env`:
```
GEMINI_API_KEY=paste_your_key_here
EXPLAIN_BACKEND=local
```
> 🔒 Never commit `.env` or paste your key in code, screenshots, or chats. (`.gitignore` already excludes it.)

## 5. Run the app

**Option A – terminal:**
```bash
uvicorn main:app --reload
```

**Option B – VS Code debugger:** press **F5** (uses `.vscode/launch.json`).

Open **http://127.0.0.1:8000** in your browser. A green "Gemini connected" badge appears at the top when your key is loaded. Interactive API docs: **http://127.0.0.1:8000/docs**.

## 6. Test it

### In the browser (functional testing)
| Tab | Try this |
|---|---|
| ❓ Ask | `Which is the largest ocean?` |
| 💡 Explain | `Photosynthesis` (first run downloads the local model — be patient) |
| 📝 Summarize | Paste any long paragraph |
| 🎯 Quiz | `The Pythagoras Theorem` → click answers; wrong ones reveal the correct option |
| 🗺️ Learning Path | `SQL` |

### With curl (API testing)
```bash
curl "http://127.0.0.1:8000/qa?question=Why%20is%20the%20sky%20blue%3F"

curl -X POST http://127.0.0.1:8000/explain \
  -H "Content-Type: application/json" -d '{"topic":"Photosynthesis"}'

curl -X POST http://127.0.0.1:8000/summarize \
  -H "Content-Type: application/json" -d '{"text":"Paste a long paragraph here..."}'

curl -X POST http://127.0.0.1:8000/quiz \
  -H "Content-Type: application/json" -d '{"text":"Solar System"}'

curl "http://127.0.0.1:8000/learn/recommendations?topic=SQL"
```
(Windows PowerShell: use `curl.exe` and escape quotes as `'{\"topic\":\"Photosynthesis\"}'`, or just use the `/docs` page.)

### Automated tests (no API key or internet needed — AI calls are mocked)
```bash
pytest
```
You can also use VS Code's **Testing** sidebar (beaker icon).

## Skipping the local model (lighter install)

If you'd rather not install PyTorch / download ~3 GB:

1. In `.env` set `EXPLAIN_BACKEND=gemini`
2. Delete the `torch`, `transformers`, `sentencepiece`, `protobuf` lines from `requirements.txt` before installing.

Explanations will then be generated by Gemini instead. Even with `EXPLAIN_BACKEND=local`, if the local model fails to load, EduGenie automatically falls back to Gemini and tells you which engine answered.

## Configuration (`.env`)

| Variable | Default | Meaning |
|---|---|---|
| `GEMINI_API_KEY` | – | **Required** for everything except local explanations |
| `GEMINI_MODEL` | `gemini-flash-latest` | Gemini model name |
| `EXPLAIN_BACKEND` | `local` | `local` or `gemini` |
| `LOCAL_MODEL_NAME` | `MBZUAI/LaMini-Flan-T5-783M` | Hugging Face model id |
| `MAX_INPUT_CHARS` | `12000` | Max input size per request |

## Troubleshooting

| Problem | Fix |
|---|---|
| Badge says "Set GEMINI_API_KEY in .env" | Create `.env` (step 4) and **restart** the server |
| `404 model not found` / model errors | The app auto-tries fallback models. You can also set `GEMINI_MODEL` in `.env` to a model your key supports (see https://ai.google.dev/gemini-api/docs/models) |
| `429` / quota message | Free-tier rate limit — wait a minute and retry |
| Explain is very slow the first time | The local model is downloading/loading (one-time). Later calls are fast |
| `ModuleNotFoundError` | Virtual environment not active/selected — redo step 3 |
| Port 8000 busy | `uvicorn main:app --reload --port 8001` |
| Quiz says it couldn't generate a valid quiz | Try again, or give a longer passage/clearer topic |

> **Note:** the original project used `google-generativeai` with `gemini-1.5-pro`. That SDK is deprecated and the 1.5 models are legacy and no longer reliably available, so this build uses the current `google-genai` SDK with a configurable model and automatic fallback.
